# Zulip to ntfy Push Service

Легковесный и высоконадежный асинхронный сервис на Python для мгновенной пересылки push-уведомлений из корпоративного чата **Zulip** на мобильные устройства и десктопы пользователей через платформу **ntfy**.

Приложение автоматически отслеживает новые сообщения во **всех публичных каналах (стримах) Zulip** и доставляет персональные уведомления подписчикам этих каналов.

---

## Как это работает

1. **Мониторинг:** Бот Zulip (с правами Администратора) слушает глобальный поток событий организации (`all_public_streams=True`).
2. **Фильтрация:** При публикации сообщения мост вытягивает список подписчиков конкретного стрима (`get_subscribers`) и отсекает автора сообщения.
3. **Адресная отправка:** Для каждого подписчика формируется HTTP POST-запрос на персональный Pub/Sub топик вида: `https://ntfy.sh/{zulip_id}`.

---

## Инструкция для пользователей: Настройка уведомлений

Чтобы начать получать мгновенные пуши на телефон или компьютер, выполните 3 простых шага:

### Шаг 1. Узнайте свой Zulip ID
1. Откройте веб-версию или приложение **Zulip**.
2. Перейдите в **Личные настройки** (Settings) -> **Профиль** (Profile).
3. Найдите строку **User ID** (это числовое значение, например: `42`). Скопируйте его.

### Шаг 2. Установите приложение ntfy
* **Android:** Скачайте ntfy из [Google Play](https://google.com) или [F-Droid](https://f-droid.org).
* **iOS:** Скачайте ntfy из [App Store](https://apple.com).
* *Также можно использовать веб-интерфейс или десктопные PWA-уведомления на сайте [ntfy.sh](https://ntfy.sh).*

### Шаг 3. Подпишитесь на свой топик
1. Откройте приложение ntfy на смартфоне.
2. Нажмите кнопку **"+"** (Subscribe to topic).
3. Введите имя вашего персонального топика: `zulip_***_{ваш_Zulip_ID}`.
   * *Например, если ваш ID равен 42, имя топика будет:* `zulip_***_42`
4. Нажмите **Subscribe**. Готово! Вы начнете получать пуши.

## Требования к боту Zulip (Для администраторов)

Для работы сквозного чтения всех каналов без ручного добавления бота в каждый стрим:
1. Создайте в панели Zulip нового бота с типом **Generic bot** (Обычный бот) и сохраните сгенерированный файл конфигурации `zuliprc` в корневую папку приложения.
2. В настройках пользователей Zulip измените роль этого бота на **Администратор организации (Organization administrator)**. Это позволит API-методу `call_on_each_event` агрегировать события со всего пространства Zulip.

## Запуск приложения

1. Установите зависимости:
   ```bash
   pip install zulip aiohttp urllib3
   ```
2. Убедитесь, что файл `zuliprc` находится в папке со скриптами `run.py` и `bridge.py`.
3. Запустите сервис:
   ```bash
   python3 run.py
   ```

## Компиляция в исполняемый файл (PyInstaller)

Чтобы запустить приложение на сервере без необходимости устанавливать Python и зависимости, его можно скомпилировать в один независимый исполняемый файл (бинарник).

1. Установите `PyInstaller` в вашем виртуальном окружении:
   ```bash
   pip install pyinstaller
   ```

2. Выполните сборку проекта одной командой:
   ```bash
   pyinstaller --onefile --name zulip-ntfy-service run.py
   ```

3. После успешного завершения процесса готовый файл появится в директории `dist/zulip-ntfy-service`.
4. Перенесите скомпилированный файл на целевой сервер (например, в папку `/usr/local/bin/`).

> ** Важно:** Файл конфигурации `zuliprc` должен лежать в той же папке, где находится скомпилированный исполняемый файл (благодаря встроенной в `run.py` проверке путей `sys.frozen`).

## Запуск как системная служба (Systemd в Linux)

Для того чтобы сервис работал непрерывно в фоновом режиме, автоматически запускался при старте сервера и корректно перезагружался при сбоях, настройте его как службу `systemd`.

### Шаг 1. Подготовка папки
Рекомендуется разместить исполняемый файл и конфигурацию в отдельной директории, например `/opt/zulip-ntfy/`:
```bash
sudo mkdir -p /opt/zulip-ntfy
sudo cp dist/zulip-ntfy-service /opt/zulip-ntfy/
sudo cp zuliprc /opt/zulip-ntfy/
```

### Шаг 2. Создание файла службы
Создайте конфигурационный файл службы:
```bash
sudo nano /etc/systemd/system/zulip-ntfy.service
```

Вставьте в него следующее содержимое:

```ini
[Unit]
Description=Zulip to ntfy Push Notification Bridge
After=network.target

[Service]
Type=simple
User=user
# Путь к рабочей директории, где лежит файл zuliprc
WorkingDirectory=/opt/zulip-ntfy
# Путь к исполняемому файлу
ExecStart=/opt/zulip-ntfy/zulip-ntfy-service
# Автоматический перезапуск службы при сбоях через 10 секунд
Restart=always
RestartSec=10
# Логирование вывода в системный журнал
StandardOutput=syslog
StandardError=syslog
SyslogIdentifier=zulip-ntfy

[Install]
WantedBy=multi-user.target
```

### Шаг 3. Активация и запуск службы
Выполните команды в терминале сервера для обновления конфигурации системных служб и запуска:

```bash
# Перезагрузить конфигурацию systemd, чтобы применить изменения
sudo systemctl daemon-reload

# Включить автоматический запуск службы при загрузке системы
sudo systemctl enable zulip-ntfy.service

# Запустить службу прямо сейчас
sudo systemctl start zulip-ntfy.service
```

### Шаг 4. Управление и просмотр логов
* Проверить **текущий статус** работы службы:
  ```bash
  sudo systemctl status zulip-ntfy.service
  ```
* Просмотр **логов приложения** в реальном времени:
  ```bash
  sudo journalctl -u zulip-ntfy.service -f
  ```
* **Перезапустить** службу после изменения файла `zuliprc`:
  ```bash
  sudo systemctl restart zulip-ntfy.service
  ```
